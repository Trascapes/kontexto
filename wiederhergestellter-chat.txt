## Wie Contexto funktioniert

Contexto ist ein Wortratespiel, bei dem du ein geheimes Wort nicht über Buchstaben, sondern über **semantische Ähnlichkeit** findest. Du gibst ein beliebiges Wort ein, und das Spiel zeigt dir eine Zahl: Je niedriger die Zahl, desto näher bist du am gesuchten Wort (1 = das gesuchte Wort selbst). Es gibt unbegrenzte Versuche, und das Spiel wird um Mitternacht Ortszeit mit einem neuen Wort zurückgesetzt. Vergangene Tage kannst du über ein Menü erneut spielen.

Technisch basiert Contexto auf **Word Embeddings** (ursprünglich GloVe), die Wörter als Vektoren darstellen und ihre Ähnlichkeit über die Kosinus-Ähnlichkeit berechnen.

## Architektur deiner deutschen Variante

Das Grundproblem: Eine reine HTML-Datei kann nicht selbst berechnen, welche Wörter ähnlich sind. Dafür brauchst du eine **Backend-Komponente** (z. B. einen Serverless-Endpunkt), die drei Aufgaben erledigt:

1. **Tägliches Wort generieren**: Eine KI-API erzeugt einmal pro Tag ein deutsches Wort.
2. **Embeddings berechnen & ranken**: Für jede Vermutung des Spielers wird die semantische Ähnlichkeit zum gesuchten Wort berechnet.
3. **Wörter speichern**: Alle generierten Wörter werden mit Datum in einer Datenbank abgelegt, damit vergangene Tage spielbar bleiben.

```javascript
// Vercel Serverless Function – berechnet den Rang einer Vermutung
export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).end();

  const { guess, date } = req.body;
  const secretWord = await getWordFromDB(date);
  if (!secretWord) return res.status(404).json({ error: 'Kein Wort für dieses Datum' });

  // Embeddings über Hugging Face Inference API (kostenlos)
  const HF_TOKEN = process.env.HF_TOKEN; // In Vercel als Env-Variable setzen
  const HF_MODEL = 'alphaedge-ai/Qwen3-Embedding-deu-16384';

  const [guessEmb, secretEmb] = await Promise.all([
    getEmbedding(guess, HF_MODEL, HF_TOKEN),
    getEmbedding(secretWord, HF_MODEL, HF_TOKEN)
  ]);

  // Kosinus-Ähnlichkeit berechnen
  const similarity = cosineSimilarity(guessEmb, secretEmb);

  // Rang ermitteln: Wir brauchen eine Liste aller möglichen Wörter.
  // Für den Anfang: Mock-Rang basierend auf Ähnlichkeit.
  // In Produktion: Vektor-Index (z. B. Pinecone, Qdrant) mit 10.000+ deutschen Wörtern.
  const rank = Math.round((1 - similarity) * 50000) + 1;
  const total = 50000; // Annahme: 50.000 Wörter im Vokabular

  return res.status(200).json({
    rank: Math.max(1, rank),
    total,
    similarity
  });
}

async function getEmbedding(text, model, token) {
  const res = await fetch(
    `https://api-inference.huggingface.co/models/${model}`,
    {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ inputs: text })
    }
  );
  const data = await res.json();
  return data[0]; // Embedding-Vektor
}

function cosineSimilarity(a, b) {
  let dot = 0, magA = 0, magB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    magA += a[i] * a[i];
    magB += b[i] * b[i];
  }
  return dot / (Math.sqrt(magA) * Math.sqrt(magB));
}
```

## Wichtige Hinweise zur Wort-Ähnlichkeit

Das **Herzstück** des Spiels ist die Rangberechnung. Im obigen Beispiel wird ein vereinfachter Mock-Rang verwendet. Für eine echte Contexto-Erfahrung brauchst du:

1. **Ein Vokabular** von mindestens 10.000–50.000 deutschen Wörtern (als Embedding-Vektoren vorberechnet).
2. **Einen Vektor-Index** (z. B. Qdrant, Pinecone oder pgvector in Supabase), in dem du die Embeddings speicherst.
3. **Bei jeder Vermutung**: Embedding des geratenen Wortes berechnen, dann den Index nach den ähnlichsten Vektoren durchsuchen und den Rang des gesuchten Wortes ermitteln.

Für den Einstieg kannst du mit einem **festen Vokabular** (z. B. die 10.000 häufigsten deutschen Substantive) beginnen und deren Embeddings **einmalig vorberechnen**. Das ist deutlich schneller als Live-Berechnung.

### Empfohlene Embedding-Modelle für Deutsch

| Modell | Quelle | Besonderheit |
|---|---|---|
| `Qwen3-Embedding-deu-16384` | Hugging Face | Speziell für Deutsch optimiert |
| `embeddinggemma-deu-16384` | Hugging Face | Google Gemma, deutsch-optimiert |
| `LightweightEmbeddings` | Hugging Face Space | Kostenlos, unbegrenzt, multilingual |
| German GloVe (deepset.ai) | Hugging Face | Klassisch, gut dokumentiert |
